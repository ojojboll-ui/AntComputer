Mitten: boet. Inre ring: variabelkammare (grön = sann, röd = falsk; storlek = lera, fylld = vinnande). Yttre ring: matautomater (krav); grön = uppfyllt, guld = mat. Tunnlarnas tjocklek = doft, färg = starkaste doftämnet. Svarta prickar = myror (ring = bär mat).
